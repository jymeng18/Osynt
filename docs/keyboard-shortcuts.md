# Keyboard shortcuts

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Send or cancel the selected request | Ctrl+Enter | ⌘+Enter |
| Save selected request | Ctrl+S | ⌘+S |
| New request | Ctrl+N | ⌘+N |
| Close selected tab | Ctrl+W | ⌘+W |
| Next request tab | Ctrl+Tab | Ctrl+Tab |
| Previous request tab | Ctrl+Shift+Tab | Ctrl+Shift+Tab |
| Focus and select the request URL | Ctrl+L | ⌘+L |
| Find in response | Ctrl+F | ⌘+F |
| Open garden | Ctrl+G | ⌘+G |

While the response search field is focused, Enter moves to the next match,
Shift+Enter moves to the previous match, and Escape closes search. Matching ignores
letter case. Search works in Pretty and Raw views and includes only the loaded preview.

Use Tab and Shift+Tab to move between controls. Closing a tab with unsaved changes
opens the save/discard prompt. Tab navigation keeps each tab's edits and response.
Click the **?** button in the title bar for an in-app shortcut reference.
